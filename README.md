# E-commerce Analytics Pipeline

An end-to-end e-commerce data pipeline built to demonstrate
data engineering, SQL, Python, backend development and data analysis.

## Project Goals

- Build a realistic relational e-commerce database
- Create a Python ETL pipeline
- Analyse business data using SQL
- Create customer and product metrics
- Build a REST API
- Create a React analytics dashboard
- Explore customer segmentation
- Experiment with an AI-powered data analysis feature

## Tech Stack

- Python
- PostgreSQL
- SQL
- FastAPI
- React
- Docker
- GitHub
